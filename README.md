# Great Mind Profile

Great Mind Profile is a Next.js App Router personality assessment site for greatmindprofile.com.

## What is included

- Server-rendered public pages for personality frameworks, methodology, contact, and policies
- Integrated client-side quiz with Quick, Standard, and Deep modes
- Local storage progress saving and anonymous result IDs
- Big Five, HEXACO-inspired, 16-type, and Enneagram-style scoring estimates
- Result page with trait bars, radar chart, strengths, blind spots, style sections, growth plan, and sharing
- Sitemap, robots, canonical metadata, Open Graph metadata, and JSON-LD helpers
- AdSense-ready account metadata and ad slot component

## Local development

```bash
npm install
npm run dev
```

Results are designed for self-reflection and educational insight. They are estimates, not diagnoses.
